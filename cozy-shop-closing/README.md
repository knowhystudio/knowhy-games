# 治愈小店打烊前（Cozy Shop Before Closing）

粉彩治愈风的 60 秒竖屏小店经营小游戏。单文件 `index.html`，中文界面，竖屏手机优先、单手操作、不引入任何外部库 / 字体 / CDN 图片，只用系统字体与 emoji / CSS 图形。

## 玩法

- 打烊倒计时 **60 秒**，顾客依次进店，想要 🌸鲜花 / 🍵热茶 / 🍞面包 三者之一。
- 点下方对应商品即服务成功：得金币（花 8 / 茶 6 / 面包 7）与暖心值 +5。
- 每位顾客有耐心条（约 11–14 秒），耐心耗尽就失望离开；同时最多 3 位等待。
- 倒计时结束弹出结算屏：**服务单数、金币、暖心值、离开顾客数**，可一键「再来一局」。

## 道具（无商店、无连击倍率）

| 道具 | 效果 |
| --- | --- |
| 🛵 快递小哥 | 立即完成一位等待顾客（按服务成功结算） |
| 💡 暖灯 | 一位顾客耐心大幅恢复（+50%） |
| 🫖 招牌茶 | 所有等待顾客耐心小幅恢复（+20%） |

每种道具**开局 1 个、上限 2 个**，只能靠局内进度补充：每成功服务 5 单随机补 1 个（不超过上限）。

## 广告接入（默认无广告）

`index.html` 内置内联适配器 `AdAdapter`，是**全文件唯一的广告注入点**（位于 `<script>` 顶部的注释块处）。默认 `enabled = false`：完全 no-op，不加载任何 SDK、不发任何外部请求。

接入方式：把 `enabled` 改为 `true`，并通过 `window.AdAdapter` 赋值两个钩子：

| 钩子 | 触发时机 |
| --- | --- |
| `interstitial: async () => void` | **插屏**：仅在「结算屏 → 再来一局」之间触发，游戏进行中绝不弹广告 |
| `rewarded: async () => boolean` | **激励**：仅当玩家在结算屏主动点「📺 看广告补 1 个道具」时触发；补的道具计入下一局开局数量，且不超过上限 2 个 |

默认无广告模式下，结算屏上的「看广告补道具」按钮点击后仅提示「当前为无广告模式」，不会有任何请求。
