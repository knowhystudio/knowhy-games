# 治愈小店打烊前（Cozy Shop Before Closing）

粉彩治愈风的 60 秒竖屏小店经营小游戏。单文件 `index.html`，中文界面，竖屏手机优先、单手操作、不引入任何外部库 / 字体 / CDN 图片，只用系统字体与 emoji / CSS 图形。

## 玩法

- 打烊倒计时 **60 秒**，顾客依次进店，想要 🌸鲜花 / 🍵热茶 / 🍞面包 三者之一。
- **点顾客卡片可选中**（明显高亮 +「✓ 已选中」标记）；选中后再服务，**暖心值翻倍**；未选中时自动服务耐心最低的、想要该商品的顾客。选中不会挡住服务其他客人。
- 服务成功得金币（花 8 / 茶 6 / 面包 7，金额在顾客卡片上飘字）与暖心值 +5；**剩余耐心一半以上服务，多得 +2 金币**（神速奖励）。
- 每位顾客有**耐心条 + 剩余秒数**（约 11–14 秒），低于 35% 时耐心条红色闪烁、卡片轻晃并出现 ⚠️；耗尽就失望离开；同时最多 3 位等待。
- 偶尔有 🦄 稀客光临，服务他**金币翻倍**。
- 顾客头像不会在等候区重复，也不会连续两次出现同一位；等候的客人想要的商品尽量错开。
- 倒计时结束弹出结算屏：**评级、服务单数、金币、暖心值、离开顾客数、历史最佳与一条改进建议**，可一键「再来一局」。打烊时还在等待的客人随打烊散去，不计入离开。

## 金币与暖心值的用途

- 金币：花 **15 金币**可换 1 个随机道具（上限 2 个/种）。
- 暖心值：选中服务 +10、稀客 +10、普通 +5；满 **30** 与满 **60** 时各获赠 1 个随机道具。
- 每成功服务 **5 单**随机补充 1 个道具（不超过上限），提示会写明补充了哪一个。

## 道具（无商店、开局即可用）

| 道具 | 效果 |
| --- | --- |
| 🛵 快递小哥 | 立即完成 1 位等待顾客（按服务成功结算） |
| 💡 暖灯 | 一位顾客耐心 +6 秒 |
| 🌿 清新香薰 | 所有等待顾客耐心 +3 秒 |

每种道具**开局 1 个、上限 2 个**，从开局第一秒就能点用（🛵/💡 优先作用于选中的顾客，否则最着急的一位）。点按道具会先弹出确认（同时暂停计时），确认后才消耗；数量为 0 时按钮变灰、不可点。若当前用不了（如还没有顾客进店），点击时会在提示条说明原因，不会无声消耗。

## 暂停与引导

- 顶栏有 ⏸️ 暂停、🔁 重新开始、❓ 玩法说明。暂停会停住倒计时与顾客耐心；切换到其他页面会自动暂停，不会悄悄结束游戏。
- 第一局有新手引导：第一位顾客会被高亮，并提示先点卡片、再点商品，完成第一单后引导消失。

## 广告接入（默认无广告）

`index.html` 内置内联适配器 `AdAdapter`，是**全文件唯一的广告注入点**（位于 `<script>` 顶部的注释块处）。默认 `enabled = false`：完全 no-op，不加载任何 SDK、不发任何外部请求。

接入方式：把 `enabled` 改为 `true`，并通过 `window.AdAdapter` 赋值钩子：

| 钩子 | 触发时机 |
| --- | --- |
| `interstitial: async () => void` | **插屏**：仅在「结算屏 → 再来一局」之间触发，游戏进行中绝不弹广告 |
| `rewarded: async () => boolean` | 激励（**预留钩子**）：当前界面没有任何入口，不会被调用；如确需接入激励广告，请先在结算屏添加真实、诚实的入口再调用 |

结算屏只有「🔁 再来一局」一个按钮，**不含任何承诺奖励的广告入口**。
