# 花园三连

选择改名为「花园三连」：实际玩法是移动植物到任意空格，横、竖、斜向三连消除，不是合并升级。保持现有小体量玩法，不引入升级链；文件夹仍为 `garden-merge`。

直接打开 `index.html` 即可游玩，无广告模式不加载 SDK 或访问外部资源。

- 每格 10 分，三格消除 +30 分；每次消除花园成长 +1。植物成长等级没有额外加分，保持原有计分代码。
- 唯一通关目标是 200 分，顶部进度条显示当前分数；未达标时满盘仍失败。普通、通关及失败后的重新开始均需确认。
- 无消除的移动补 3 株植物，顶部显示下批预览；不足 3 个空格时只补至满盘，新植物仍可触发消除。
- 开局 12 株，无现成三连，保留至少一步可消除的移动。首消前持续显示实线起点 1、虚线落点 2 及成线格；移动或铲除后按当前棋盘刷新引导。
- 阳光让一株成长 +1；浇水壶影响所选植物及上下左右相邻植物。0、1、2、3+ 级用递增大小和加深底色区分，14px 成长标记保留真实等级。选中成长道具时预览示例植物的下一等级；悬停或键盘聚焦可切换预览目标。顶部色阶让触屏玩家在使用前也能理解外观变化。成长只改变外观。
- 铲子、阳光、浇水壶初始各 1 个，上限各 2 个。铲子每次消除后有 20% 概率补充；阳光每累计 150 分补充 1 个。
- 空格 ≤10 时顶部红色警告。找三连每局 3 次，每次查找扣 1 次（含无走法），显示剩余次数；有走法则高亮相关格，用尽后禁用并说明原因。开局教学不消耗提示。

## 可重复验证

安装 Playwright 后执行 `node garden-merge/tests/smoke.cjs`。脚本使用系统 Chromium（若可用），或 Playwright 自带 Chromium；可通过 `CHROMIUM_PATH` 指定路径。不修改根目录或其他游戏。固定随机种子检查 1000 次开局，并验证消除、补种、三个道具、成长外观与计分、空格 11/10/9/0 边界、提示 3 次上限、200 分短局及重新开始确认。受控棋盘只用于边界和单项行为测试；200 分短局从真实开局运行，不注入分数或植物。

## 广告宿主接入

单文件默认使用空操作适配器。广告宿主可在游戏脚本执行前注入 `window.gardenAdsAdapter`，提供如下接口：

```js
window.gardenAdsAdapter = {
  enabled: true,
  interstitial: async () => { /* 展示并等待插屏关闭 */ },
  rewarded: async (tool) => { /* tool 为 shovel、sun 或 water；完整观看返回 true */ return false; }
};
```

游戏仅在终局后玩家点击再来一局并确认重新开始时调用插屏；仅在玩家主动选择未达到上限的道具时调用激励广告。适配器抛错不会阻止重新开始，激励失败不会发放道具。SDK 的加载与实现由广告宿主负责。
