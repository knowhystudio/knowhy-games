# KNOWHY GAMES catalog

This static game catalog is adapted from [Formwork Isometria](https://github.com/shellcat-com/formwork-isometria) under its MIT license (`LICENSE`). The homepage uses a studio-level illustrated CSS banner and a compact, expandable game-card grid. The older licensed Three.js files remain in `vendor/` for source provenance and are excluded from static deployment assets.

`/` introduces the studio's games. `/classroom-snacks/` describes Classroom Snacks and links to [itch.io](https://knowhy.itch.io/classroom-snacks) and [Playgama](https://playgama.ai/play/3tqjeyv6y7). Gameplay and the score board are not embedded in the catalog; the game client and score Worker are separate.

All routes support 14 locales: Simplified Chinese, English, Japanese, Korean, Spanish, Brazilian Portuguese, French, German, Russian, Thai, Vietnamese, Indonesian, Turkish, and Polish. The visible site-language control persists an explicit choice in localStorage; without one, the site starts in English regardless of browser language. Page metadata and accessible labels use the same locale catalog.

No build system, account, or contact form is required by the site source. After changing translation values, run `node scripts/sync-english-fallback.mjs` to keep the no-script HTML copy in English. The Cloudflare account currently injects its Web Analytics beacon into live HTML; that is a platform setting, not part of this repository. For local review, run `python3 -m http.server 5199 --bind 127.0.0.1 --directory .` from the repository root, then open `http://127.0.0.1:5199/`. Run `node scripts/check-i18n.mjs` for locale-catalog consistency checks and `node --test tests/locale.test.mjs` for the catalog and page-binding test suite. Review all routes at narrow and desktop widths before publication. `wrangler.jsonc` targets the existing Cloudflare custom domain; local edits do not update the public site.
