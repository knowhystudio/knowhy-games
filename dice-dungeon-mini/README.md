# 骰子地牢小局

竖屏单文件小游戏，无需构建、框架或联网。可直接打开 `index.html`，或从仓库根目录运行 `python3 -m http.server 5199 --bind 127.0.0.1`，访问 `http://127.0.0.1:5199/dice-dungeon-mini/`（云端受管 Chromium 禁止 file URL，因此测试使用本地 HTTP）。每局有 3 个房间：掷骰后攻击，击败怪物获得宝藏；前两个房间结束后选择一项升级。生命归零结束本局，胜利或失败后均可重新开始。局中“重开本局”需确认；取消保留当前进度，确认重置本局。

## 规则与数值

- 怪物依次为史莱姆（生命 9、反击 2）、骷髅（生命 15、反击 3）、守卫（生命 21、反击 3）。怪物卡在掷骰及攻击前都显示反击伤害；击杀一击不承受反击伤害。
- 重掷、药水、护盾初始各 1 个、各上限 2 个。宝藏只补充未满的道具；全部满时明确提示无法领取，不再无声丢弃奖励。没有商店或复杂背包。
- 重掷：先点选任意一颗已掷出的骰子，显示编号及原值后再重掷；新值先预览，可保留原结果或确认新结果。每次消耗 1 个道具，即使保留原值也不退还；确认前禁止攻击和使用其他道具。
- 药水：生命 +4，不超过当前生命上限。使用前显示实际恢复与浪费点数；满血显示“将浪费 4 点”且禁止使用，部分溢出需确认，取消不消耗道具。
- 护盾：最多激活 1 面，抵挡下一次反击后消耗。跨房间保留，击杀不消耗；顶部状态在战斗、升级、结算中持续可见。

| 升级 | 数值及上限 | 初次选择时的效果 |
| --- | --- | --- |
| 力量 | 每颗骰子伤害 +1，另加固定伤害 +3；最多 2 级（每骰 +2、固定 +6） | 单骰平均伤害 3.5 → 7.5，伤害范围 5–10 |
| 治疗 | 生命上限 +4，再恢复 +4；上限由初始 20 提升，最高 28 | 满血 20/20 → 24/24，确保升级无浪费 |
| 额外骰子 | 每次攻击 +1 颗六面骰；初始 1、最多 3 颗 | 平均伤害 3.5 → 7，伤害范围 2–12 |

力量提供稳定的提升，额外骰子有更高的随机上限；力量也随骰子数增长，治疗增加生存空间。各选项实时显示升级前后的生命、骰子数或平均伤害（未重掷的六面骰期望值为 3.5）。完整伤害公式为：骰子点数之和 + 力量等级 × 骰子数 + 力量等级 × 3。

每次攻击计 1 回合。胜败结算均显示通过房间数、回合数、总攻击伤害（含溢出）、剩余生命和三种剩余道具，以及尚未消耗的激活护盾。

## 广告适配

默认无广告：不引入 SDK，也不发起外部请求。广告版本由宿主在游戏脚本运行之前注入 `window.DiceDungeonAds`，可提供以下异步方法：

- `showInterstitial()`：仅在本局结束后点击重新开始时调用；失败也会开始新局。局中重开不调用广告。
- `showRewarded()`：仅在房间结束后的升级界面，由玩家主动点击按钮时调用；返回或 resolve `true` 才发放一个随机未满的道具。返回其他值或抛错均无奖励。

广告 SDK 的加载、合规和生命周期由宿主负责。未提供对应方法时不调用；未提供激励方法时不显示激励按钮。所有奖励遵守每种道具 2 个的上限。

- `shots/victory.png`：固定随机序列的可复现通关，8 回合、总伤害 47、生命 14/20，剩余重掷 0、药水 1、护盾 1（均含最后宝藏）。验证重掷 2 → 3 并确认新值，以及第 2 颗 5 → 1 后保留原值；护盾从第一房间击杀保留到第二房间，挡住 3 点反击后消耗；药水将生命从 16 恢复到 20。
- `shots/random-victory.png`：另一次未控制随机数的实际通关，依次使用自选重掷、护盾、药水。第 2 颗骰子 3 → 2 后保留原值；护盾挡住 3 点反击；药水恢复 4 点（16 → 20）。各房间攻击伤害分别为 2+6+5、9+10、14+11；7 回合、总伤害 57、最终生命 17/20，剩余重掷 1、药水 2、护盾 0（含最后宝藏）。

`game.test.cjs` 的 8 项浏览器回归测试全部通过：三房间完整流程、满血禁用与部分治疗浪费的取消/确认、待确认重掷中的局中重开取消/确认、三种升级各连选两次后的数值与上限、道具满额/激励奖励/结算重开、死亡结算（11 回合、伤害 19、生命 0/20）。

测试需要 Node.js 与测试环境安装的 `playwright`，运行时游戏本身无依赖。使用已安装的系统 Chromium 运行：

```sh
CHROMIUM_PATH=/usr/bin/chromium node --test dice-dungeon-mini/game.test.cjs
```

省略 `CHROMIUM_PATH` 则使用 Playwright 自带浏览器。可设置 `DD_SCREENSHOTS` 为仓库外目录以保存可复现流程的截图与轨迹；无需修改根目录文件或增加锁文件。
