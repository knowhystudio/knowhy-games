# 骰子地牢小局

竖屏单文件小游戏，直接用浏览器打开 `index.html` 即可游玩，无需构建或联网。每局有 3 个房间：掷骰后攻击，击败怪物获得宝藏；前两个房间结束后从加伤害、回血、多一颗骰子中选择一项升级。生命归零结束本局，胜利或失败后均可重新开始。

重掷、药水、盾牌各从 1 个开始，各自上限为 2 个。重掷第一颗已掷出的骰子；药水恢复最多 4 点生命；盾牌抵挡下一次反击。房间宝藏随机补充一种未满的道具，没有商店或复杂背包。

## 广告适配

默认无广告：不引入 SDK，也不发起外部请求。广告版本由宿主在游戏脚本运行之前注入 `window.DiceDungeonAds`，可提供以下异步方法：

- `showInterstitial()`：仅在本局结束后点击重新开始时调用；失败也会开始新局。
- `showRewarded()`：仅在房间结束后的升级界面，由玩家主动点击按钮时调用；返回或 resolve `true` 才发放一个随机未满的道具。返回其他值或抛错均无奖励。

广告 SDK 的加载、合规和生命周期由宿主负责。未提供对应方法时不调用；未提供激励方法时不显示激励按钮。所有奖励遵守每种道具 2 个的上限。

## 截图与测试

`shots/gameplay.png` 是在云端 Chromium 中以 375 × 812 视口加载本 HTML 并实际操作时截取的运行画面。测试通过 3 个房间并胜利，重掷、药水、盾牌各使用 1 次，重新开始 1 次；375px 视口的页面宽度和滚动宽度均为 375px，无横向溢出。测试期间无页面脚本错误及外部请求。
